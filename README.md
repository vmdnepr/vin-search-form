# VIN Search — Carvertical

Плагин WordPress показывает на сайте форму поиска автомобиля по VIN. Посетитель вводит номер и нажимает кнопку. Плагин открывает партнёрский сайт Carvertical в новой вкладке и передаёт в ссылку введённый VIN вместе с партнёрскими параметрами.

Автор: Vladimyr. Текущая версия: 1.4.

## Установка

1. Скопируйте папку `vin-search-form` в `wp-content/plugins/`. Внутри папки должен лежать файл `vin-search-form.php`.
2. В админке WordPress откройте «Плагины» и включите **VIN Search - Carvertical**.
3. Вставьте шорткод туда, где должна появиться форма: страница, запись или виджет с поддержкой шорткодов.

```
[vin_search]
```

Других шорткодов и блоков у плагина нет. Форма не отправляет VIN на сам сайт: номер уходит только в адресе новой вкладки партнёра.

## Что видит посетитель

Форма состоит из поля с подсказкой `ENTER VIN`, знака вопроса и кнопки `DECODE VIN`.

- Пустое поле не открывает партнёра. Появляется сообщение `Please enter your VIN code`.
- Подсказка у знака вопроса: `VIN - це унікальний набір із 17 символів`.
- Заполненное поле открывает ссылку в новой вкладке. Номер подставляется вместо метки `{vin}`.
- Если шорткод стоит на странице несколько раз, стили и скрипт выводятся один раз.

Язык ссылки определяется в браузере по адресу открытой страницы. Из-за этого кэш страницы не запоминает чужой язык.

## Настройки

Страница находится в **Настройки → VIN Search**. Открыть её может только администратор. У страницы две вкладки: **Ссылка** и **Дизайн**. Сохранение одной вкладки не затирает вторую.

Все настройки лежат одной записью в таблице `wp_options`, имя записи `vin_search_settings`. Запись не подгружается на каждой странице сайта: WordPress читает её, когда на странице есть шорткод или открыты настройки плагина. Если плагин раньше хранил параметры отдельными опциями, при первом обращении они переносятся в эту запись и старые опции удаляются.

### Вкладка «Ссылка»

#### Parameter A, Parameter B, Voucher

Три отдельных поля партнёра. Их значения подставляются в метки `{a}`, `{b}` и `{voucher}`.

По умолчанию уже стоят рабочие коды Carvertical, а voucher равен `vincodeonlineeu`. Коды A и B содержат специальные символы, поэтому их лучше копировать, а не перепечатывать. Менять поля нужно только если партнёр выдал новые значения.

Кнопка «Вернуть ссылку Carvertical» восстанавливает шаблон адреса и не трогает A, B и Voucher.

#### Партнёрская ссылка

Шаблон по умолчанию:

```
http://www.carvertical.com/ua/precheck?a={a}&b={b}&voucher={voucher}&vin={vin}
```

Ссылку можно собрать двумя способами, они связаны между собой:

- поле **Домен и путь** меняет сайт и путь, параметры при этом сохраняются;
- таблица **Параметры ссылки** задаёт имя и значение каждого параметра, лишние строки удаляются кнопкой в строке;
- поле **Ссылка целиком** показывает итоговый шаблон, его можно править вручную.

Кнопка «Добавить параметр» добавляет пустую строку. Пока у параметра нет имени, строка не попадает в ссылку.

В значении параметра можно оставить метку, например `{voucher}`, или написать постоянный текст. Адрес принимается только с `http://` или `https://`. Если протокол не указан, плагин дописывает `https://`.

Ниже показывается итоговая ссылка, предупреждение, если в ней нет `{vin}`, и ссылка «Проверить ссылку с тестовым VIN». Проверка открывает адрес с номером `1HGCM82633A123456`.

#### Метки в ссылке

| Метка | Когда подставляется | Откуда берётся значение |
| --- | --- | --- |
| `{a}` | при выводе страницы | поле Parameter A |
| `{b}` | при выводе страницы | поле Parameter B |
| `{voucher}` | при выводе страницы | поле Voucher |
| `{vin}` | в браузере, по нажатию кнопки | текст из поля формы |
| `{lang}` | в браузере, по нажатию кнопки | сегмент языка партнёра |

Старая запись `{{vin}}` при сохранении приводится к `{vin}`.

#### Язык в ссылке

Переключатель **«Подставлять язык из адреса нашего сайта»** по умолчанию выключен. Пока он выключен, поля сопоставления скрыты, а метка `{lang}` в ссылке не заменяется.

После включения можно добавить сколько угодно пар:

- слева сегмент адреса нашего сайта, например `ru` для страницы `/ru/`;
- справа сегмент сайта партнёра, например `ru` или `ua`.

Сегмент — это текст между слешами, без самих слешей. Сравнение не зависит от регистра: `/UK/` совпадёт с `uk`. Берётся первое совпадение в адресе страницы. Если сегмент не найден или у найденной пары пустой партнёрский сегмент, подставляется запасное значение из поля «Если в адресе нет такого сегмента, подставить».

В пути партнёрской ссылки должна стоять метка `{lang}`, иначе сопоставление ни на что не влияет. Кнопка **«Вставить {lang} в путь»** заменяет первый сегмент пути. Из адреса по умолчанию получается:

```
http://www.carvertical.com/{lang}/precheck?a={a}&b={b}&voucher={voucher}&vin={vin}
```

Пример. На сайте есть `/ru/`, в паре указано `ru` → `ru`, запасной сегмент `ua`. Посетитель со страницы `/ru/...` попадёт на `.../ru/precheck...`. Посетитель со страницы без известного сегмента попадёт на `.../ua/precheck...`.

Под таблицей языков плагин показывает примеры готовых адресов для каждой пары.

### Вкладка «Дизайн»

Два режима.

**Использовать шрифт и цвета сайта.** Поле и кнопка прозрачные, текст и рамка берутся у страницы, тень отключается, размер шрифта наследуется.

**Задать свои цвета и шрифт.** Этот режим включён по умолчанию и повторяет прежнюю жёлтую кнопку.

| Поле | Значение по умолчанию |
| --- | --- |
| Цвет поля | `#ffffff` |
| Цвет текста в поле | `#333333` |
| Цвет рамки поля | `#e0e0e0` |
| Цвет кнопки | `#FFD220` |
| Цвет текста кнопки | `#333333` |
| Цвет кнопки при наведении | `#ffe066` |
| Шрифт | пусто, то есть шрифт сайта |

Пример шрифта: `Georgia, serif`. В своём режиме размер текста формы равен 16px.

Блок **Предпросмотр** сразу показывает поле и кнопку с выбранными цветами. Рядом выводится строка «Текст страницы рядом с формой», чтобы в режиме сайта было видно наследование.

**Свой CSS** сохраняется и выводится на сайте после основных стилей формы. Для правки подходят селекторы `#vin-search-form`, `#vin-input` и `#search-button`. В предпросмотре эти селекторы автоматически показываются на макете. Длина поля ограничена 20 000 символами. Из текста убираются HTML-теги, `@import`, `expression(`, `javascript:`, `behavior`, привязки и `data:`.

Кнопка сохранения на этой вкладке называется «Сохранить дизайн».

## Обновления

Плагин смотрит последний релиз репозитория https://github.com/vmdnepr/vin-search-form. Если номер в шапке файла плагина выше установленной версии, WordPress показывает обычное обновление.

Чтобы выпустить следующую версию:

1. Поднимите `Version` в начале `vin-search-form.php`.
2. Отправьте изменения в ветку `main`.
3. Опубликуйте релиз с тегом выше текущей версии, например `v1.5.0`.

Тег должен начинаться с номера версии, при необходимости с буквой `v` в начале. Релиз `v1.4.0` соответствует версии 1.4 и сам по себе обновление не предлагает.

Сайту, на котором плагин ещё без проверки GitHub, эту версию нужно поставить один раз вручную. Дальше обновления приходят из релизов.
